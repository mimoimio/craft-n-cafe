# QPTR Checklist

## Promise
- [ ] Packaging matches the first 5 minutes: serve, upgrade, build, expand.
- [ ] Attracts cafe/building players, not just clicks.

## Title
- [ ] Genre + fantasy + differentiator.
- [ ] 3 variants tested.
- [ ] Short enough for mobile.

## Icon
- [ ] Readable at small size.
- [ ] One focal point.
- [ ] Matches the thumbnail style.

## Thumbnails
- [ ] 3 variants.
- [ ] Before/after cafe or clear action shot.
- [ ] Character + drink/cash + build progress.
- [ ] High contrast, no small text, mobile-safe crop.

## Video
- [ ] 15-30 seconds.
- [ ] Hook in first 3 seconds.
- [ ] Shows serve -> upgrade -> build -> expand.
- [ ] Captions and clear end card.

## Screenshots
- [ ] 6-8 images.
- [ ] Drinks, serving, workers, building, expansion, customization.

## Description and tags
- [ ] Clear promise and controls.
- [ ] Update cadence.
- [ ] Tags: tycoon, cafe, restaurant, simulator, building, cooking, cute, relaxing.

## Measurement
- [ ] QPTR baseline recorded.
- [ ] CTR recorded.
- [ ] One packaging variable changed per week.
- [ ] Keep the best-performing variant.
