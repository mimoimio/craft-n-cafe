# 6 Metrics and its corresponding variables
**1) Average Playtime**

* Satisfying core loop
* Haptics and feedback on buttons
* SFX (sound effects)

**2) D1 (Day 1 Retention): Tutorial**

* Great onboarding
* Clear and easy to follow
* **Clear GOALS and MOTIVATION**, dangle these maybe:
>* Placeables
>* Expansion
>* Upgrades
>* Completion (recipe panel)
* Track progress using **FUNNELS**
* **SHOW, don't TELL**

**3) D7 (Day 7 Retention)**

* Social flex (leaderboards) <- (this is important cuz now its the only one)
* Goals / more content (later)
* Admin abuse & live events (prolly not this now)

**4) Payer CVR (Conversion Rate)**

* **Starter packs** (cheapest — e.g., 20 R$)
* **Consumables** (cheap, repeatable):
> * *"Double offline earnings?"* or
> * *"Double daily rewards"* or
> * *"Skip?"* (e.g., 9 R$)

**5) ARPPU (Average Revenue Per Paying User)**

* Game passes (e.g., 400 R$) for whales — **EXPENSIVE**
* Like fries: Small, Medium, Large (e.g., Starter, Pro, OP)

**6) QPTR (Qualified Playthrough Rate): Marketing**

* Packaging: Thumbnails, videos, title
